# Fonts — Butterick's verdicts and lists

Professional fonts are "the fastest, easiest and most obvious upgrade." Most free fonts are garbage; most system fonts are mediocre and all are overexposed. But good choices exist in both.

## System fonts, letter-graded

- **A-list** (tolerable for body text): Athelas, Avenir, Bell MT, Book Antiqua, Californian FB, Calisto MT, Century Schoolbook, **Charter**, Franklin Gothic, Garamond, Gill Sans (MT), Goudy Old Style, Helvetica (Neue), Hoefler Text, Iowan Old Style, Optima, Palatino, Seravek, Sitka
- **B-list** (fine in limited doses — headings, UI, short runs): Calibri, Candara, Constantia, Corbel, Futura, Geneva, Perpetua, Rockwell, Segoe UI, Bodoni MT, Centaur, High Tower Text
- **C-list** (questionable): Baskerville, Cambria ("a skull-clutcher" in print), Century Gothic, Consolas, Courier (New), Didot, Georgia, Impact, Lucida (all), Menlo, **Times New Roman**
- **F-list** (fatal to credibility): **Arial** ("the sans serif of last resort" — "you cannot create good typography with Arial"), Comic Sans, Brush Script, Copperplate, Monaco, Monotype Corsiva, Papyrus, Parchment, Stencil, Tahoma, Trebuchet MS, **Verdana**, Zapfino, and all script/novelty faces

Times New Roman is "not a font choice but the absence of a font choice… it connotes apathy."

## Context rules

- Print → A-list only. Screen (web, slides, drafts) → A + B.
- **PDF → print-grade fonts always** — any PDF may be printed. Same reason: keep PDF body text black, not dark gray.
- Georgia, Verdana, Cambria, Calibri are screen-optimized: clunky on paper, keep them off print and PDF.
- Goofy/novelty/script fonts: no professional document; billboard-style signage only.
- Monospaced: code only, never body text. Good monos: Triplicate, Pitch, Input, Fira Mono (free, endorsed "without reservation"), Source Code (free).

## Endorsed free fonts

Charter (Matthew Carter — "holds up beautifully on today's screens"), Source Serif, Source Code, Cooper Hewitt, IBM Plex (Sans/Serif/Mono — designed as a matching set), Fira Mono.

## Judging an unlisted font

The lists are exemplary, not exhaustive. A candidate passes if it is: professionally designed (named designer/foundry, not a template-mill output); equipped — multiple real weights, true italics (not slants), and real small caps or at least tabular figures; not overexposed as a platform default; and role-appropriate (screen faces on screen, print-grade in print/PDF). Serif vs. sans is not a quality axis — modern screens render both well.

## Pairing

Two fonts per document is the tolerable maximum for most; three rarely; four never. Any two identifiably different fonts can pair — serif+sans is a convention, not a rule; low contrast between two serifs can work (newspapers do it). Each font keeps one consistent role (body vs. headings vs. code). Change fonts only at paragraph-level boundaries. Reliable shortcut: pair fonts by the same designer (e.g., IBM Plex Sans + Plex Mono).
